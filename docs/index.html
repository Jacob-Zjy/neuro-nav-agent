KNOW THE BOUNDARIES

值得理解的，
还有这些边界。

清楚地说明已经实现什么，
也是可复现研究的一部分。

这个项目已经接入大语言模型了吗？+

当前 v0.1 使用确定性工具编排：条件检查、排序、权重抽样与证据审核均由 Python 模块完成。大语言模型交互和自由文本条件提取属于后续方向，尚未在本版本实现。

排名第一，就可以报名参加吗？+

不能。当前候选范围包含 ACTIVE_NOT_RECRUITING（进行中但不再招募），示例第一项即为该状态。排名表示有限字段下的相关性，完整入排标准和实际招募情况必须回到登记页面，并由试验协调员确认。

0.997 的分数能说明什么？+

它描述受控合成病例上的平衡准确率。病例与规则使用相同的结构化字段定义，结果用于检查软件行为，不能据此声称临床验证、诊断能力或真实患者效果。

数据里有真实患者的信息吗？+

没有参与者级数据。项目使用公开试验登记元数据和明确标注的合成画像。研究画像仅包含疾病、年龄、登记性别类别和国家，不需要姓名、联系方式或病历标识。
